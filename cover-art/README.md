# Cover art

Working files for the blog's cover images. Nothing here is published; the site only uses covers inside `site/`.

- `LOG.md`: every cover, the starting image it was painted from, and the prompt.
- `sources/`: the starting images.
- `style-pack/`: drop this folder into a new ChatGPT session. `STYLE.md` is the brief, `references/` are finished covers to match.
